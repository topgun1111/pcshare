### 12.2 Scan engine (`core/StorageScan.kt`)
```kotlin
StorageScan.start(dir: File, label: String, usedBytes: Long): Scan   // returns at once; 4 daemon threads
StorageScan.get(id) / cancel(id) / latest(dir) / running(dir) / adopt(...) / removeFile / removeNode / pruneNested / deniedBelow
class Scan { state "run|done|cancel|error", error, cancel, files/dirs/bytes (live AtomicLong), denied, deniedSample, cur,
             percent() (-1 unknown, max 99 until done), millis(), root: SNode?, top: List<SNode>, catBytes(), catFiles(), find("/DCIM/Camera"),
             limited, truncated, loaded, removed, job }
class SNode { name, dir, parent, size, files, folders, cat, agg, denied, cats: LongArray?, kids: Array<SNode>, path() }
object SCat { OTHER IMG VID AUD DOC ARC APP, COUNT, KEYS, of(fileName) }
```
- **Memory**: a folder keeps only its 200 largest files as nodes; the rest is ONE synthetic `agg` node (`name ""`, `files` = count) so sums stay exact; empty folders are dropped from `kids` (still counted in `folders`). Node limit per scan = heap / 700 B, 150,000-400,000 (`nodeLimit`), plus a live check (< 32 MB heap left = stop keeping single files, `Scan.truncated`). Memory keeps the newest 3 finished scans and <= 700,000 nodes together.
- **Speed**: one task per folder on a 4-thread pool (breadth first); one `Files.readAttributes(NOFOLLOW_LINKS)` per entry on API 26+; symlinks skipped; sizes are apparent (`length`). Totals filled by a finishing pass (post-order, 16 MB stack thread); `root` / `top` set only when `done`.
- **Unreadable folders** (Android/data on API 30+ without All-files access): `node.denied`, `Scan.denied`, first 20 paths in `deniedSample`. Categories by extension (`SCat.of`): images, video, audio, documents, archives, apps (apk, obb), other; bytes per folder in `SNode.cats`, file counts only for the whole scan.
- **Job**: every scan is a normal `Job` (`sscan:<id>`, label "Analyzing storage" / "Analyzing <folder>"), mirrored ~6 times a second by `StorageScan.mirror`; the job's Cancel sets the cancel flag.
- **Delete patching** (`removeFile` / `removeNode`, synchronized): detach the node, subtract size / files / folders / `cats[]` up the chain, drop emptied ancestors, re-sort, adjust `Scan.top`, `files`, `bytes`, `removed`.

### 12.3 API (all GET in `Routes.api`, helpers `sscan*`)
Category arrays always in `SCat.KEYS` order `other img vid aud doc arc app`. Errors `{error}` + status (404 unknown scan / folder, 400 not finished).
- `/api/sscan?path=/&rescan=0` -> `{id, state, path, whole, error}` (`path=/` = whole main storage with `usedBytes` = total - usable; other path = that folder, percentage -1). Returns the running scan, else the newest finished one, else starts one; `rescan=1` skips the finished one.
- `/api/sscanp?id=` -> `{state, percent, files, dirs, bytes, used, cur, error, ms, denied, keys, catFiles[7]}` (+ when done `catBytes[7], total, folders, deniedSample[]`).
- `/api/sscannode?id=&path=/DCIM&n=60` (n 1..500) -> `{id, path, name, size, files, folders, denied, cats[7], kids[], rest?}`; kid `{n, d, s, f, ...}` (folder adds `fo`, `cats[7]`, `x:true`; file adds `c`; "N small files" = `a:true`, `n:""`); `rest = {count, s, f}`. Paths are scan-relative.
- `/api/sscantop?id=` -> `{id, top:[{n, p, s, c}]}` (100 largest); `/api/sscancancel?id=`. `InProc.ROUTES` has `sscanp`, `sscannode`, `sscantop`.

### 12.4 Screen and views (`StorageActivity.kt`)
- Plain Activity, extra `path` (`/` = whole main storage; `X_VOL` for another volume), `StorageActivity.intent(ctx, vpath)`; own light / dark palette (`AppPal`, same as `JobOverlay.Palette`); process death re-attaches by `path`. Header: back, title, **Rescan** (hidden while scanning); volume card (used bar, Used / Free / Total, red under 5 % free); states: run (percent, bar, counts, current folder, elapsed, **Cancel**; keeps running if you leave), done, cancel / error ("Scan again" + "Show the previous result"). Compact mode (height < 640 dp) hides the volume card.
- `attach()` order: running scan -> newest finished in memory -> saved copy (`StorageStore`, gzip in cache `sscan/`, one file per folder, newest 4, max 7 days, then `StorageScan.adopt`) -> new scan. A result made without All-files access is not reused once access is on.
- **Treemap** (`StorageTreemap`, squarified, flat arrays, cap 20,000 tiles, nesting <= 12; category colours `CAT_COL`; first tap selects, second tap opens / details; `hl` highlights a category). **List** (`StorageList`, hand-drawn rows, `setFilter(cat)`, `setFlat(top)` for **Largest**, multi-select by long press). **Tabs** Treemap | List | Largest (`showIn(n)` jumps to the file's folder). **File-type bar** (`paintCats`, tap = highlight / filter). Back order: select mode -> Largest -> up one folder -> leave. Breadcrumb + info line (Open / Details / File manager / Show).
- **Details dialog**: type, size + exact bytes, % of folder / scan, real path, actions Open, Open with, Share, **Show in file manager** (`MainActivity` `ACTION_SHOW_PATH` + `X_SHOW_PATH`, `runShowPath()` -> `lsGoLocal(p)`; folder only, no highlight), red **Delete...** (not the scan root, not "small files"). Files outside primary storage toast.
- **Delete**: `confirmDelete` (size, counts, bin note `Bin.KEEP_DAYS`, denied-part warning) -> `deleteNode` (`Bin.trash`) -> `afterDeleteMany` patches the tree and refreshes once; multi-select -> `confirmDeleteMany`. Not on other volumes.
- **System / other** = `usedBytes - (root.size + Scan.removed)` with `sysDialog` (Android, app private data / caches, other users, block rounding, Android/data note, unreadable folders, **Allow access**). **All files access**: `needAccess()` = `Core.storageOk == false`, red banner, `Scan.limited`, `onResume` rescans after access is granted.
- **Other volumes** (`core/Volumes.kt`; API 30 `directory`, below hidden `getPath()`, fallback `getExternalFilesDirs`): chips Internal storage + one per volume at the root; volume = view + Open / Open with / Share only. A removed volume falls back to internal.

### 12.10 Free up space (cleaner, extended 2026-10-23; uncompiled, no device test)
`core/Cleanup.kt` (`GET/POST /api/cleanup`) + `openFreeUp()` in ui.html (drawer > Free up space). Result keys `free total bin{items,bytes} reclaim{count,bytes}` and lists `big old apk junk empty shots chat` = `{count, bytes, items[{path,size,m,d}]}` (`d` = empty folder).
- **junk**: temp / log / bak / old / chk / dmp / unfinished-download files older than 3 days, everything in `.thumbnails/.thumbs/.cache/.tmp`, `.trashed-*`, `Thumbs.db`, `desktop.ini`, `~$*`, `*~`, `._*`. **empty**: topmost folders without any file (standard top-level folders kept) + 0-byte files. **shots**: Screenshots / Screen recordings older than 30 d. **chat**: WhatsApp / Telegram media older than 90 d and >= 256 KB, also `Android/media/com.whatsapp*|org.telegram*|org.thunderdog*`. **reclaim** = every file of junk / empty / old / apk / shots / chat counted once (big files excluded).
- Page: summary card (free-up total, used bar, **Quick clean** = junk + empty folders in one confirmation, **Analyze storage** -> `LSAndroid.openStorage('/')`), the sections, then Duplicate files / Similar pictures. All deletes go through `/api/rm` (Recycle bin). Open: compile + device test, `.cache` hidden-dir handling, whether `Bin.trash` accepts `Android/media/...`.

### 12.11 Other devices (read-only, 2026-10-21; not compiled / device-tested)
The pill also works on **LANShare phones, SMB, FTP and SFTP** (not Root, not inside archives). `StorageScan.startRemote(dev, vpath, label)` builds the same `SNode` tree; `Scan.remote` / `Scan.dev` mark it and `StorageActivity.ro` (archive or remote) switches off open / share / delete / reveal / multi-select. Results live in memory only (`remoteKey`, never saved).
- **LANShare phone, new build**: the phone scans ITSELF (`/p/sscan`), this phone polls `/p/sscanp` every 0.4 s and downloads the finished tree once with `/p/sscandl` (`StorageStore.encode` / `decode`, gzip); `/p/sscancancel` cancels. **Old build** (404): its `/p/walk` is folded locally (`walkScan`). **SMB**: folder-per-task, 8 parallel `lsFast` calls. **FTP / SFTP**: same on 4 threads (the pool size), depth cap 48, unlistable folder = "unreadable".
- UI: `usedPct()` / `pillSet()` feed the pill (and native `NlHead` `u`) from `/api/space`; `LSAndroid.openStorageDev(dev, name, path)` -> `StorageActivity.intentDev`. No pill where there is no space number (SMB server root, FTP without `space`).
- Limits: nothing can be opened / deleted from a remote scan; speed depends on folder count; no byte-based percentage on folder scans.
